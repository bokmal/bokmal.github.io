수식정원 개인정보처리방침

Ru.M Studio · 안내 기준일: 2026-09-30

출시 준비 초안입니다. 아래는 수식정원 0.6.1의 현재 데이터 처리 기준이며, 어린이 포함 출시를 위한 연령·광고 보호와 로그인·클라우드 동기화는 개발 예정입니다. 해당 기능 구현 후 최종 방침을 갱신합니다.

기기에 저장하는 정보

수식정원은 퍼즐 진행과 완료 기록, 힌트, 오늘의 퍼즐 기록, 정원 장식, 닉네임, 선택한 프로필 사진, 화면·소리·진동 설정을 기기에 저장합니다. 이 정보는 게임 진행과 사용자가 선택한 기능 제공에 사용합니다. 회원가입과 자체 계정 서버는 없습니다.

프로필 사진

사진은 사용자가 시스템 선택창에서 직접 고릅니다. 선택한 사진은 자르기 후 프로필에 표시되며 앱이 별도 서버로 자동 업로드하지 않습니다. 프로필에서 사진을 제거하고 저장하면 앱에 저장한 사진을 삭제합니다.

광고 서비스

배너와 선택형 보상 광고에 Google AdMob을 사용합니다. 광고 서비스는 IP 주소를 통한 대략적인 위치, 앱·광고 상호작용, 진단 정보, 기기 및 기타 식별자 등을 광고 제공·측정·오류 진단·부정 사용 방지에 처리할 수 있습니다. 적용되는 설정과 이용자 선택에 따라 처리 범위가 달라집니다. 비개인화 광고도 광고 제공에 필요한 정보를 처리할 수 있습니다.

광고 선택

힌트 충전과 시간 연장 광고는 사용자가 선택해 시청합니다. 필요한 지역에서는 광고 개인정보 선택 화면을 제공하며, 변경 가능한 경우 설정의 광고 개인정보 설정에서 다시 선택할 수 있습니다. Google 서비스의 처리는 Google 개인정보처리방침과 광고 설정을 따릅니다.

기록 파일

기록 내보내기를 선택하면 사진을 포함한 게임 기록을 사용자가 지정한 위치에 저장합니다. 클라우드 저장 위치를 직접 선택하면 해당 파일 서비스의 약관과 개인정보처리방침이 적용됩니다. 앱은 백업 파일을 자동 업로드하거나 동기화하지 않습니다.

보관과 삭제

로컬 기록은 해당 기기에 유지되며 앱 데이터 삭제 또는 앱 삭제 시 일반적으로 제거됩니다. 사용자가 따로 저장한 백업 파일은 해당 저장 위치에서 직접 삭제해야 합니다. 광고 서비스가 처리하는 정보의 보관·삭제는 해당 서비스 정책과 이용자 권리 요청 절차를 따릅니다.

안전한 처리

게임 기록은 앱 전용 저장 공간에 보관합니다. 외부 파일은 가져오기 전에 형식과 내용을 검사합니다. 광고 SDK의 네트워크 정보 전송에는 암호화된 연결을 사용합니다. 백업 파일은 사진과 기록이 포함될 수 있으므로 개인 저장 공간에 보관해주세요.
